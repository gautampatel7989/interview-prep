# What is Microservice Communication?

In a microservices architecture, each service owns its own data and business logic.
Services communicate over the network, not via shared databases or code.

# Example:

User Service → user profile

Order Service → orders

User Service calls Order Service to fetch user orders

# Types of Communication

1️⃣ Synchronous (Request–Response)

REST (HTTP/HTTPS)

gRPC

Characteristics

Caller waits for response

Simple and commonly used

Suitable for read operations

Example

User Service → HTTP GET → Order Service

2️⃣ Asynchronous (Event-Driven)

Kafka
RabbitMQ
AWS SQS
Characteristics
Non-blocking
Highly scalable
Used for background tasks
Why Services Should Communicate via APIs Only
Loose coupling
Independent deployments
Fault isolation
Technology agnostic

A. ORDER SERVICE (Provider)
Purpose

Provides order data by userId.

# Folder Structure

order-service/
├── controllers/
│ └── order.controller.js
├── routes/
│ └── order.routes.js
├── app.js
└── server.js

```javascript
// order.controller.js
exports.getOrdersByUserId = async (req, res) => {
  const { userId } = req.params;

  // Mock DB data
  const orders = [
    { id: 1, userId: "101", item: "Laptop", price: 70000 },
    { id: 2, userId: "101", item: "Mouse", price: 1200 },
  ];

  const userOrders = orders.filter((o) => o.userId === userId);

  res.json({
    success: true,
    data: userOrders,
  });
};

order.routes.js;
const express = require("express");
const router = express.Router();
const { getOrdersByUserId } = require("../controllers/order.controller");

router.get("/orders/user/:userId", getOrdersByUserId);

module.exports = router;

app.js;
const express = require("express");
const orderRoutes = require("./routes/order.routes");

const app = express();
app.use(express.json());
app.use("/api", orderRoutes);

module.exports = app;

server.js;
const app = require("./app");

app.listen(4001, () => {
  console.log("Order Service running on port 4001");
});
```

B. USER SERVICE (Consumer)
Purpose

Fetch user data and call Order Service to get orders.

Folder Structure
user-service/
├── services/
│ └── order.service.js
├── controllers/
│ └── user.controller.js
├── routes/
│ └── user.routes.js
├── app.js
└── server.js

```javascript
order.service.js (Service-to-Service Call)
const axios = require("axios");

const ORDER_SERVICE_URL = "http://localhost:4001/api";

exports.getUserOrders = async (userId) => {
const response = await axios.get(
`${ORDER_SERVICE_URL}/orders/user/${userId}`
);
return response.data.data;
};

user.controller.js
const { getUserOrders } = require("../services/order.service");

exports.getUserWithOrders = async (req, res) => {
const { userId } = req.params;

// Mock user data
const user = {
id: userId,
name: "Gautam Patel",
email: "gautam@example.com"
};

try {
const orders = await getUserOrders(userId);

    res.json({
      success: true,
      data: {
        user,
        orders
      }
    });

} catch (error) {
res.status(500).json({
success: false,
message: "Order Service unavailable"
});
}
};

user.routes.js
const express = require("express");
const router = express.Router();
const { getUserWithOrders } = require("../controllers/user.controller");

router.get("/users/:userId", getUserWithOrders);

module.exports = router;

app.js
const express = require("express");
const userRoutes = require("./routes/user.routes");

const app = express();
app.use(express.json());
app.use("/api", userRoutes);

module.exports = app;

server.js
const app = require("./app");

app.listen(4000, () => {
console.log("User Service running on port 4000");
});
```
