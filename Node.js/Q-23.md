# What is npm ci ?

npm ci stands for Clean Install. It is a command used to install Node.js project dependencies exactly as defined in package-lock.json.

## Key Points

- Installs dependencies strictly from package-lock.json
- Deletes node_modules before installing
- Faster and more predictable than npm install
- Mainly used in CI/CD pipelines

# How npm ci Works

- Removes existing node_modules
- Reads package-lock.json
- Installs exact versions (no updates, no changes)
- Fails if package-lock.json is missing or out of sync

# npm install vs npm ci

- Feature npm install npm ci
- Uses package.json Yes No
- Uses package-lock.json Optional Mandatory
- Updates lock file Yes No
- Deletes node_modules No Yes
- Speed Slower Faster
- Best for Development CI/CD

# When to Use npm ci

- Automated builds
- CI/CD pipelines (Jenkins, GitHub Actions, GitLab CI)
- Production deployments
- When consistent dependency versions are required

# Simple Example

npm ci
Ensures every environment installs the same dependency versions.
