# 1. Can we create an async function without await?

✅ Yes, we can.

- An async function always returns a Promise, even if it does not contain await.
- async is mainly a syntax sugar over Promises.
- Using async without await is valid but often unnecessary unless
- You want a Promise-returning function
- You plan to add await later
- You want consistent function signatures

Example

```javascript
async function getUser() {
return { id: 1, name: "Gautam" };
}

getUser().then(console.log);

What actually happens
function getUser() {
return Promise.resolve({ id: 1, name: "Gautam" });
}
```

# When this is useful

- API contract expects a Promise
- Interface consistency
- Frameworks that expect async handlers

# 2. Can we use await without async?

❌ Generally, NO.

- await must be inside an async function
- Otherwise, JavaScript throws a SyntaxError

❌ Invalid Example

```javascript
function fetchData() {
const data = await getUser(); // ❌ Error
}
```

Error
SyntaxError: await is only valid in async functions

# 3. ✅ Exception: Top-Level await (Modern JavaScript)

Allowed in:

- ES Modules (.mjs)
- "type": "module" in package.json
- Modern Node.js (v14+ with ES modules)

Example (Top-Level Await)
// index.mjs

```javascript
const data = await fetch("https://api.example.com/users");
console.log(data);
```

✔ No async function required
✔ Works only at top-level scope

# 4. Summary Table (Interview-Friendly)

Question Answer

- Async function without await? ✅ Yes
- Await without async? ❌ No
- Exception? ✅ Top-level await
- Async returns? Always a Promise

# 5. Interview One-Line Answer

“An async function can exist without await because it always returns a Promise, but await cannot be used without async, except at the top level in ES modules.”
